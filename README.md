# 臺南市立大灣高中｜社會探究與實作課程票選系統

## 完成的功能
- 手機、電腦可填班級、座號、姓名後投票。
- 管理者可設定每人最多 1～99 票，每項候選同學／作品最多一票。
- 一位學生一次提交全部選票，可少於上限；提交後不能再投。同一班級、座號不因更換姓名或裝置而增加票數。
- 公開頁面只顯示候選項目與票數；完整投票明細需後端驗證登入後才能取得。
- 後台可設定票選名稱、說明、開放／關閉，新增或停用候選項目，匯出 CSV。
- 登出會使後端登入憑證失效；登入最長六小時，也可能提早因快取清除失效。
- 停用候選項目後歷史投票名稱仍保留；初始化不清除既有資料。

## 目前發布狀態
前端已發布至 [票選網站](https://dwhs270-glitch.github.io/dawuan-social-inquiry-voting/)，共用後端已部署並連接。預設投票關閉，請先在後台新增候選項目，再開放投票。
GitHub 存放原始碼與前端；私密 Google 試算表儲存投票資料，Apps Script 負責登入與投票驗證。
不需 Firebase 或 Cloudflare，也不需學生登入 Google。

## 建立共用資料後端
1. 建立一份專用 Google 試算表，保持私人，不開啟連結分享。
2. 選「擴充功能 → Apps Script」，貼入 backend/Code.gs。
3. 在「專案設定 → 指令碼屬性」新增 ADMIN_USER 與 ADMIN_PASSWORD，分別填入教師指定帳號、密碼。
4. 執行 setup() 並完成 Google 授權；初始化後這兩個原始值會移除，改存雜湊。
5. 選「部署 → 新增部署作業 → 網頁應用程式」，執行身分為「我」，存取者為「任何人」。若學校帳號政策不提供此選項，須由管理員開放或使用適合的帳號。
6. 將部署的 /exec 網址填入 config.js 的 API_URL。
7. 第一次登入 admin.html，新增實際候選項目、設定票數，再開放投票。預設為關閉且無候選項目。

## GitHub 網站發布

## 使用方法
教師：開啟 admin.html → 登入 → 新增候選 → 儲存票數和開放狀態 → 分享 index.html 網址。
學生：填本人班級、座號、姓名 → 勾選候選項目 → 確認送出。
教師：重新整理後台 → 查閱完整資料或匯出 CSV。
課堂結束：將投票狀態改為關閉。

## 實際限制
班級需為三位數，座號為 1～99。全形數字及前導零會統一處理。
本系統以學生自行填寫資料識別，沒有學籍名冊驗證；因此可防同一身分重複投票，不能阻止冒用別人的班級與座號。
一份試算表同時管理一場票選。下一場可先匯出紀錄，再使用後台「刪除本次票選並重設」清空；也可建立獨立試算表與後端保留舊場次。
票數重新整理時更新。GitHub Pages 與 Apps Script 的跨網站實際連線、Google 帳號政策及多人並發仍須在部署後驗證。
